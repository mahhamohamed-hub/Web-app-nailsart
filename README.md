# Angel's Touch by Malak ✨

**Luxury nail art atelier & booking experience** with a charming patisserie theme.

A modern web application that lets clients design custom nail art, book appointments with artists, save their "recipes", and interact with an AI-powered Chef chatbot — all wrapped in an elegant bakery-inspired interface.

## Features

- 🎨 **Interactive Nail Canvas** – Design and customize nail art in real time
- 🥐 **Pastry Case** – Browse service tiers presented as delicious pastries
- 📅 **Booking System** – Real-time appointment scheduling with artists
- 📖 **Recipe Book** – Save and manage your custom nail designs
- 🛍️ **Bakery To Go** – Press-on / takeaway nail options
- 💬 **Chef Chatbot** – AI assistant powered by Google Gemini
- 🛡️ **Admin Panel** – Manage appointments, artists, and clients
- 🇲🇦 Designed for a high-end nail atelier in Morocco

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Express (server)
- Google Gemini AI
- Motion (animations)
